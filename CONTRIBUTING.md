# Contribution Guidelines

Thank you for considering contributing to the Afrifinance project! Your contributions help to enhance the project and its community. Here are some guidelines to help you get started:

## 1. Getting Started
- **Fork the repo:** Create your own copy of the repository by forking it.
- **Clone the repo:** Clone your forked repository to your local machine using `git clone https://github.com/cypskip-create/Afrifinance.git`.
- **Create a branch:** Before making any changes, create a new branch for your feature or bug fix. Use `git checkout -b your-branch-name`.

## 2. Making Changes
- Make your changes in your local repository.
- Ensure that your code adheres to the style and guidelines of the project.

## 3. Testing
- Write tests for any new features you add or any bug fixes you implement.
- Make sure all tests pass before submitting a pull request.

## 4. Submitting a Pull Request
- Push your changes to your forked repository using `git push origin your-branch-name`.
- Navigate to the original repository and click on ‘New Pull Request’.
- Provide a clear description of your changes and why they are necessary.

## 5. Code of Conduct
Please adhere to the project's [Code of Conduct](link-to-code-of-conduct) in all interactions.

Thank you for your interest in contributing! Together we can make Afrifinance even better!
